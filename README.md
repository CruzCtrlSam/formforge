# FormForge V1

Open `index.html` in a browser to try the beta. For GitHub Pages, copy this folder's contents, including `.nojekyll`, into a dedicated repository. In **Settings → Pages**, deploy from the main branch and repository root.

The app runs entirely in the browser. Setup, active workouts, history, and body check-ins are stored locally for the current browser and site address. Exports contain personal measurement data if you entered it. Clearing site storage erases local progress. The rest timer uses a saved end time and catches up after the screen wakes.

Start with **Today**, view the four-week roadmap in **Plan**, review measurements and workout history in **Progress**, and find personalized snack ideas in **Snacks**. Week 1 is repeatable.
